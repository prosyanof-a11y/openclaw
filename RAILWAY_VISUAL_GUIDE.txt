❌ Still seeing "Usage: openclaw [options] [command]" ?

Solution 1: Check variables are actually saved
  → Variables tab → All 3 variables should be visible and have values

Solution 2: Force redeploy
  → Deployments → Three dots menu → "Force New Deployment"

Solution 3: Check API key format
  → OPENROUTER_API_KEY should start with "sk-or-"
  → TELEGRAM_BOT_TOKEN should be format "123456:ABC..."
  → No spaces before/after values!

Solution 4: Wait longer
  → Sometimes takes 2-3 minutes for variables to apply
  → Wait 5 minutes total before troubleshooting

Solution 5: Check Logs
  → Deployments → Logs
  → Search for "Error" or "FATAL"
  → Read the error message
