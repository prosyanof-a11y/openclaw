# ❓ OpenClaw Railway Deployment - FAQ

Часто задаваемые вопросы о развертывании на Railway.

## Общие вопросы

### Что такое OpenClaw?

**OpenClaw** - многоканальный AI шлюз, который позволяет:
- Подключаться к различным каналам общения (Telegram, Discord, WhatsApp и т.д.)
- Использовать разные AI модели (OpenRouter, Anthropic, OpenAI и т.д.)
- Создавать AI agents для автоматизации задач
- Маршрутизировать сообщения между каналами

### Зачем нужен Railway?

Railway предоставляет:
- **Простое развертывание**: Просто подключите GitHub репозиторий
- **Автоматическая сборка**: Railway собирает Docker образ автоматически
- **Масштабируемость**: Масштабирование ресурсов по мере необходимости
- **Мониторинг**: Встроенный мониторинг и логирование
- **Бесплатный уровень**: 500 часов в месяц на бесплатном плане

## Установка и настройка

### Сколько времени занимает развертывание?

Обычно:
- **Первый раз**: 5-10 минут (сборка Docker образа)
- **Последующие**: 1-2 минуты (использование кэша)

### Какие переменные окружения необходимы?

**Обязательные:**
- `OPENROUTER_API_KEY` - для использования AI моделей
- `TELEGRAM_BOT_TOKEN` - для интеграции Telegram

**Опциональные:**
- `OPENCLAW_GATEWAY_TOKEN` - для безопасности API (генерируется автоматически если не установлена)
- `LOG_LEVEL` - для уровня логирования (по умолчанию: info)

### Где получить API ключи?

**OpenRouter:**
1. Перейдите на https://openrouter.ai
2. Зарегистрируйтесь / войдите
3. Откройте https://openrouter.ai/keys
4. Скопируйте API ключ

**Telegram Bot Token:**
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/start`
4. Отправьте `/newbot`
5. Следуйте инструкциям
6. Скопируйте токен

### Бесплатно ли это?

**Railway:**
- Бесплатный уровень: 500 часов в месяц (~$5/месяц)
- Платные планы от $5/месяц
- OpenClaw использует примерно 720 часов в месяц (24/7 работа)

**OpenRouter:**
- Pay-as-you-go модель
- Цены зависят от используемой модели
- Примерно $0.01-0.50 за 1000 токенов

**Telegram:**
- Полностью бесплатно

## Технические вопросы

### Что такое Dockerfile?

**Dockerfile** - это файл с инструкциями как собрать Docker образ:
- Установка зависимостей
- Копирование исходного кода
- Компиляция TypeScript
- Настройка запуска приложения

Railway автоматически выполняет эти инструкции для сборки образа.

### Почему используется Docker?

Docker позволяет:
- **Консистентность**: Одинаковое окружение везде (локально и на Railway)
- **Изоляция**: Приложение не конфликтует с другими сервисами
- **Простота**: Все зависимости упаковываются в один образ
- **Масштабируемость**: Легко запустить несколько копий

### Что такое WebSocket?

**WebSocket** - протокол для двусторонней коммуникации:
- Постоянное соединение между клиентом и сервером
- Низкая задержка (latency)
- Используется для real-time взаимодействия

OpenClaw Gateway использует WebSocket на порту 18789.

### Можно ли изменить порт?

Да, но нужно изменить несколько мест:

**На Railway (переменная окружения):**
```bash
PORT=8080
```

**В коде (если нужно):**
```bash
openclaw gateway --port 8080
```

По умолчанию используется порт 18789.

## Проблемы и решения

### Где смотреть логи?

**В Railway UI:**
1. Откройте Dashboard
2. Нажмите на ваш проект
3. Откройте вкладку "Logs"
4. Ищите сообщения о старте/ошибках

**Через Railway CLI:**
```bash
railway logs --follow
```

### Почему приложение перезагружается?

**Обычные причины:**
1. Переменные окружения не установлены
2. Crash приложения
3. Out of Memory (недостаточно памяти)
4. Manual redeploy

**Как исправить:**
1. Проверьте все переменные окружения в Settings → Vars
2. Посмотрите логи на ошибки
3. Запросите больше памяти (Settings → Resources)

### Приложение медленное

**Возможные причины:**
1. OpenRouter API медленный (обычно 5-20 сек)
2. Модель обрабатывает сложный запрос
3. Недостаточно ресурсов на Railway
4. Плохое сетевое соединение

**Как оптимизировать:**
1. Используйте более быстрые модели (например: `openrouter/auto`)
2. Запросите больше CPU/RAM на Railway
3. Добавьте кэширование ответов
4. Используйте асинхронную обработку

### Ошибка "Connection refused"

**Причины:**
1. Gateway не запущен
2. Неправильный URL
3. Файрволл блокирует соединение

**Как исправить:**
1. Проверьте статус приложения на Railway (должен быть "Running")
2. Проверьте URL: `https://<название-проекта>.up.railway.app`
3. Подождите несколько секунд (может быть медленный старт)
4. Посмотрите логи на ошибки

### Ошибка "Invalid token"

**Причины:**
1. TELEGRAM_BOT_TOKEN неправильный
2. Токен скопирован с пробелами
3. Token был переиспользован или удален

**Как исправить:**
1. Скопируйте токен снова от @BotFather (без пробелов)
2. Убедитесь что в Settings → Vars нет лишних пробелов
3. Нажмите "Redeploy"

## Интеграции

### Как добавить новый канал (Discord, WhatsApp и т.д.)?

1. Найдите расширение в папке `extensions/`
2. Установите необходимые credentials (токен, пароль и т.д.)
3. Добавьте переменную окружения на Railway
4. Перезагрузите приложение

Пример для Discord:
```bash
# На Railway добавьте переменную
DISCORD_BOT_TOKEN=<ваш_токен>

# Затем нажмите Redeploy
```

### Как использовать разные AI модели?

OpenRouter поддерживает множество моделей:

```bash
# OpenAI GPT-4
openrouter/openai/gpt-4

# Anthropic Claude
openrouter/anthropic/claude-opus-4.6

# Open Source модели
openrouter/mistralai/mistral-7b

# Auto (выбирает лучшую по цене)
openrouter/auto
```

Используйте в запросах:
```bash
curl -X POST https://<ваш-проект>.up.railway.app/api/agent \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Hello",
    "model": "openrouter/openai/gpt-4"
  }'
```

### Могу ли я использовать свой OpenAI ключ?

Да, но нужно модифицировать конфигурацию:

1. Вместо OPENROUTER_API_KEY используйте OPENAI_API_KEY
2. Измените модель на `openai/gpt-4` (вместо `openrouter/...`)
3. Нажмите Redeploy

**Плюсы:**
- Часто дешевле чем OpenRouter
- Полный контроль над моделями

**Минусы:**
- Нужна отдельная регистрация
- Требует более сложная конфигурация

## Масштабирование

### Можно ли запустить несколько копий?

Да, через Railway Replicas:

1. Откройте Settings
2. Перейдите в Services
3. Увеличьте количество Replicas (3 = 3 копии)

Railway будет:
- Запустить несколько копий приложения
- Распределять трафик между ними
- Перезапускать упавшие копии

### Сколько стоит масштабирование?

Railway использует модель Pay-as-you-go:
- $0.000555/час за 1 GB памяти
- $0.000462/час за 1 CPU

Пример 3 копии по 1 GB:
- 3 × 1 GB × 30 дней × 24 часа × $0.000555 ≈ $12/месяц

### Сколько трафика может выдержать?

Это зависит от ресурсов:
- **1 копия 512MB**: ~100 одновременных соединений
- **1 копия 1GB**: ~500 одновременных соединений
- **3 копии по 1GB**: ~1500 одновременных соединений

OpenRouter может быть узким местом при большом трафике.

## Безопасность

### Безопасно ли открывать API публично?

OpenClaw использует токены для аутентификации:
- OPENCLAW_GATEWAY_TOKEN для Gateway API
- TELEGRAM_BOT_TOKEN для Telegram
- Другие токены для других сервисов

**Рекомендации:**
1. Используйте надежные/случайные токены
2. Регулярно ротируйте токены
3. Не коммитьте токены в Git
4. Используйте переменные окружения (как сейчас на Railway)

### Могу ли я скрыть API от публики?

Да, используя Railway Environments или приватные сети:

1. Используйте Railway Private Networks
2. Или используйте API ключи для аутентификации (см. выше)
3. Или запустите на приватной сети через VPN

## Обновления и поддержка

### Как обновить OpenClaw?

Railway автоматически использует последнюю версию из GitHub:

```bash
# Вариант 1: Pull latest from GitHub
git pull origin main

# Вариант 2: Через GitHub UI
# Нажмите "Redeploy" в Railway Dashboard

# GitHub Actions обновит приложение автоматически
```

### Как откатить до предыдущей версии?

На Railway:
1. Откройте Deploy history
2. Нажмите на предыдущий deployment
3. Нажмите "Redeploy"

Через GitHub:
```bash
git revert <commit-hash>
git push origin main
```

## Примеры использования

### Простой чат-бот в Telegram

```
1. Разверните OpenClaw на Railway
2. Создайте Telegram бота у @BotFather
3. Установите TELEGRAM_BOT_TOKEN
4. Установите webhook
5. Готово! Бот будет отвечать на сообщения
```

### AI assistant через API

```bash
curl -X POST https://<ваш-проект>.up.railway.app/api/agent \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Привет! Как дела?",
    "model": "openrouter/openai/gpt-4"
  }'
```

### Интеграция с внешним сервисом

```javascript
import fetch from 'node-fetch';

const response = await fetch('https://<ваш-проект>.up.railway.app/api/message/send', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    channel: 'telegram',
    target: '@mychannel',
    message: 'Hello from external service!'
  })
});
```
