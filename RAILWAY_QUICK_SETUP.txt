                    RAILWAY - БЫСТРАЯ УСТАНОВКА ПЕРЕМЕННЫХ
================================================================================

❌ ПРОБЛЕМА: OpenClaw показывает справку CLI вместо запуска
✅ РЕШЕНИЕ: Нужно установить переменные окружения на Railway

================================================================================
                              ШАГ ЗА ШАГОМ
================================================================================

1️⃣  Откройте Railway Dashboard
   URL: https://railway.app/dashboard
   
2️⃣  Выберите проект "openclaw"
   Dashboard → Найти ваш проект → Кликнуть
   
3️⃣  Перейдите на вкладку "Variables"
   В меню слева или сверху найти "Variables" или "Vars"
   
4️⃣  Добавьте ТРИ переменные (скопируйте точно):

   ┌──────────────────────────────────────────────────────────────┐
   │ ПЕРЕМЕННАЯ 1: OPENROUTER_API_KEY                             │
   │ ──────────────────────────────────────────────────────────── │
   │ Key:   OPENROUTER_API_KEY                                    │
   │ Value: sk-or-... (получить на https://openrouter.ai/keys)   │
   │                                                               │
   │ ✅ Add Variable                                              │
   └──────────────────────────────────────────────────────────────┘

   ┌──────────────────────────────────────────────────────────────┐
   │ ПЕРЕМЕННАЯ 2: TELEGRAM_BOT_TOKEN                             │
   │ ──────────────────────────────────────────────────────────── │
   │ Key:   TELEGRAM_BOT_TOKEN                                    │
   │ Value: 123456:ABC... (получить у @BotFather в Telegram)    │
   │                                                               │
   │ ✅ Add Variable                                              │
   └──────────────────────────────────────────────────────────────┘

   ┌──────────────────────────────────────────────────────────────┐
   │ ПЕРЕМЕННАЯ 3: OPENCLAW_GATEWAY_TOKEN                         │
   │ ──────────────────────────────────────────────────────────── │
   │ Key:   OPENCLAW_GATEWAY_TOKEN                                │
   │ Value: a7f2c9e4b1d6f3a8c5e9b2d7f4a1c8e5                    │
   │        (или любая другая строка из 32+ символов)            │
   │                                                               │
   │ ✅ Add Variable                                              │
   └──────────────────────────────────────────────────────────────┘

5️⃣  Сохраните
   Нажмите "Save" или переменные сохранятся автоматически

6️⃣  Перезапустите приложение
   Railway → Deployments → Force New Deployment
   или подождите ~2 минуты на автоматический перезапуск

7️⃣  Проверьте логи
   Deployments → Logs → ищите "Gateway starting"

================================================================================
                             ПОЛУЧИТЬ API КЛЮЧИ
================================================================================

OPENROUTER_API_KEY:
  1. Откройте https://openrouter.ai/keys
  2. Скопируйте ваш API ключ (начинается с "sk-or-")
  
TELEGRAM_BOT_TOKEN:
  1. Откройте Telegram
  2. Найдите @BotFather
  3. Напишите /start
  4. Выберите своего бота или /newbot
  5. Скопируйте токен (цифры:буквы_цифры)

OPENCLAW_GATEWAY_TOKEN:
  Любая случайная строка, например:
  a7f2c9e4b1d6f3a8c5e9b2d7f4a1c8e5
  или сгенерируйте на https://generate-secret.vercel.app/32

================================================================================
                           ПРОВЕРКА РЕЗУЛЬТАТА
================================================================================

После установки переменных должны видеть в логах:

✅ 🦞 OpenClaw ... 
✅ Gateway starting on ws://0.0.0.0:18789
✅ Health check: OK
✅ Telegram bot connected (если TELEGRAM_BOT_TOKEN установлен)

ЕСЛИ ВСЕ ЕЩЕ НЕ РАБОТАЕТ:
  1. Очистите кэш: Settings → Redeploy → Force New Deployment
  2. Проверьте синтаксис ключей (нет пробелов, кавычек)
  3. Посмотрите Logs → ищите Error/FATAL
